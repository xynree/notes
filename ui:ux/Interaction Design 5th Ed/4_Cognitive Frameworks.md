# 4 - Cognitive Frameworks

# 4.2 - What is Cognition?

- Experiential vs reflective cognition
  - Experiential: perceiving, acting, reacting to events around person
  - Reflective: mental effort, attention, judgement, decision making
- Fast & Slow Thinking
- Specific Kinds of Processes
  - Attention
  - Perception
  - Memory
  - Learning
  - Reading, Speaking, Listening
  - Problem-solving, planning, reasoning, decision-making

- Attention
  - Selecting things on which to concetrate, at a point of time, from the range of possibilities available.
  - Enables us to focus on relevant information
  - Depends on: Clear Goals
    - Attention different when there are clear goals vs unclear goals (example: finding news vs. menu at restaurant)
    - Presentation: Displaying information different ways influences how easy/difficult to understand information
  - Whether info is salient to environment
  - Design Implications
    - Make info salient when it requires attention at the given stage of the task
    - Avoid cluttering interfaces with too much info
    - Design different ways of switching/returning to interface

- Perception
  - How info is adquired from the environment via sense organs
  - Grouping itens and leaving space can aid attention
  - Chunks of information are easier to scan
  - Use blank space when grouping objects
  - Design Implications
    - Icons/GUIS should be easily distinguished
    - Obvious separaters and white space are good methods for grouping information
    - Design audio to be distinguishable
    - Haptic feedback should be used carefully - don't overuse

- Memory
  - Recalling various kinds of knowledge
  - Filtering: Used to decide what process info gets memorized
  - We often forget things we would like to remember
  - The more attention paid to something and the more it is processed, the more likely to be remembered
  - How info is interpreted when encountered greatly affects how it is represented in memory and how easy it is to retrieve.
  - People are better recognizing things than recalling things
  - Personal info management
    - How to name, categorize, and then relocate items after storing them digitally?
    - Naming is commonly used to encode content
    - Adding metadata to documents - most people prefer using folders
  - Design Implications:
    - Avoid long and complicated procedures to reduce cognitive load
    - Interfaces should promote recognition rather than recall by using familiar concepts (patterns, menus, icons, consistently placed objects)
    - Provide variety of ways to label digital info

- Learning
  - Closely connected with memory
  - Accumulation of skills & knowledge
  - Incidental learning - without intention to learn
  - Intentional learning - goal directed learning
  - Collaborating often helps people with learning
  - Design implications:
    - Design to encourage exploration
    - Design to constrain and guide users when initially learning the interface

- Reading, Speaking, Listening
  - 3 Forms language processing which have slightly different properties:
    - Written = permanent, listening = transient
    - Reading is quicker than speaking/listening
    - Listening requires less cognitive effort
    - Written language = grammatical, Spoken = non grammatical
  - Design Implications:
    - Keep length of speech baased menus and instructions to a minimum (should not have more than 3/4 options)

- Problem Solving, Planning, Reasoning, Decision Making
  - Involve conscious processes, discussion, various artifacts
  - Design technological interfventions that provide just enough info and in the right form to faciliatate good choices
  - Provide info and help pages that are easy to access
  - Enable users to set or save their own criteria or preferences

# 4.3 Cognitive Frameworks

- Mental Models: Used when needing to reasono about a technology
- Using incorrect mental models to guide behavior is very common
- Design technologies to be more transparent:
  - Provide instructions
  - Give online help, tutorials, context-sensitive guidance
  - Background info that can be accessed to let people know how something works
  - AFfordance of what actions an interface allows
- Gulfs of Execution and Evaluation
  - Describes gaps that exist between user and interface
  - Execution: Distance from user to physical system
  - Evaluation: Distance from phsycial system to user
- Human processor model of info processing
  - input -> encoding -> comparison ->response selection -> execution
- Distributed Cognition
  - Describe cognitive system and the enviornment they are working in in terms of how information moves through the media (transformations of information)
- External Cognition
  - Reduces memory load: notes
  - Offloading: Using pen and paper to calculate
  - Annotating/Cognitive tracing: modifying representations, manipulating items into different ordres
